快麦扫码查询 · 客户安装手册
============================

一、你需要准备三样东西
  1. 安装包            快麦扫码查询_安装版_v1.7.exe
  2. 证书两个文件      <域名>.crt  和  <域名>.key        （例如 kmcx.cc.crt / kmcx.cc.key）
  3. frp token         一行字符串（服务器那边给你的，必须完全一致）

二、安装（3 步）
  1. 双击安装包
     · 向导里「服务器地址」已预填 106.52.122.158（也可改成你的域名）
     · 向导里「frp token」→ 填上面那串 token
     · 下一步 → 安装（勾上"开机自动启动"）
  2. 打开程序「快麦扫码查询」→「API 设置」→ 填快麦的
     appKey / appSecret / refreshToken / sessionId
  3. 把证书文件 <域名>.crt 和 <域名>.key 一起拖到程序目录下的
     「装证书.cmd」上（它会自动放好并重启 HTTPS 中转，并自测）

三、所有东西装在哪（排查时按这个找）
  <安装目录> = C:\Users\<用户名>\AppData\Local\KuaimaiScan
  ┌──────────────┬─────────────────────────────────────────────┬──────────┐
  │ 程序         │ <安装目录>\快麦扫码查询.exe                 │ 端口 8790 │
  │ HTTPS 中转   │ <安装目录>\kuaimai_https\km_https.exe      │ 端口 9443 │
  │ 证书         │ <安装目录>\kuaimai_https\lego\certificates\<域名>.crt / <域名>.key │
  │ frp 客户端   │ <安装目录>\frp\frpc.exe                     │           │
  │ frp 配置     │ <安装目录>\frp\frpc.toml（安装向导自动生成）│           │
  │ 快麦 API     │ <安装目录>\kuaimai_api.json（界面里填）      │           │
  │ 数据         │ <安装目录>\kuaimai_data.db / scan_log.db     │           │
  │ 访问地址     │ https://<域名>:9443/                          │           │
  └──────────────┴─────────────────────────────────────────────┴──────────┘

四、验收（3 条都过就算装好）
  1. 端口： netstat -ano | findstr "8790 9443"      → 两个都 LISTENING
  2. 本机： 浏览器打开 https://<域名>:9443/           → 证书显示 <域名>，无警告
  3. 外网： 手机切 4G（关 Wi-Fi）打开同一地址         → 能开摄像头扫码

五、常见问题
  · 打不开/一直转圈
      - 服务器防火墙要放行 7000 与 9443
      - token 必须和服务器完全一致
      - 本机 9443 没在听 → 先双击「① 启动全部.bat」，或看中转是否有证书
  · 提示证书不受信任/警告
      - 证书域名必须和访问域名一致；用 IP 访问一定报警告
      - 换证书：把新的 crt/key 再拖一次「装证书.cmd」
  · 被安全软件拦截 / 启动就闪退
      - 把 <安装目录>、C:\kuaimai_frp、C:\frp 加入白名单（不要关杀软）
  · 换电脑对外服务
      - 同一时间只能一台电脑对外提供 9443；旧电脑先执行：
        schtasks /Delete /TN KuaimaiFrpc /F

六、证书到期
  免费证书一般 90 天–1 年。重新申请后，把新的 crt/key 再拖一次「装证书.cmd」即可。

七、想确认隧道连没连上
  浏览器打开服务器面板 http://<服务器IP>:7500/
  应看到 1 个客户端、2 条隧道（9443 与 443）。

【装完想改这些，不用重装】
  打开桌面「快麦扫码查询」→ 用管理员账号登录 → 主界面「操作」区点【对外访问设置】：
  · 域名 / frp 服务器地址 / 端口 / frp token：改完点「保存并重启隧道」
  · 换 HTTPS 证书：点「选择 .crt 和 .key 并安装…」（两个一起选，会自动校验是不是一对）
  · 状态区能一眼看到：对外地址、8790/9443 有没有在听、frpc 在不在跑、证书到期日
  · 开机自启：同一个窗口勾一下即可
